# learn_github_basic_v1-project

GitHub 是当今管理和协作文本的业内标准. 不管是代码, 文档, 笔记还是任何以文字存在的东西, 放上去就自动带上了版本历史, 协作工具和一条永久的记录. 很多人以为这是程序员专属的地方, 而它真正的底子是作品加社交: 一个作品有地方放, 而且这个地方自带主页, 认可, 关注和一条谁也伪造不了的时间线. 这门课教它最核心的基础工作流, 从纯网页操作起步, 逐步扩展到访问权控制, 再落到本地的 GitHub Desktop, 全程不碰命令行.

学完你手上会多出一整套能自己走完的工作流程: 独立管好一个项目, 拿分支安全地试错再把成果并回主线, 精确决定谁能看谁能改, 让程序代表你去操作, 并且在自己电脑上顺手地完成这一切. 这是真实团队每天都在走的路径, 掌握了它, 你就具备了参与现代协作项目的基本功. 更实际的一层收获是, 你从此有了一个公开的, 带时间戳的地方来存放自己做过的东西, 而在今天, 一份能点进去看过程的记录, 比简历上任何一行形容词都值钱. 课程定位是 basic, 深度刚好覆盖能自己独立走完一整轮.

这是一门纯阅读型的课, 不需要配置任何环境, 也不需要额外的工具. 内容拆成 examples 目录下按编号排列的一篇篇 Task, 从第一篇的系列索引开始, 顺着编号读下去就行, 每一篇都配一份 TICKET 让你当场自查有没有真的学会. 想开始的话, 从根目录的 [README-cn.md](README-cn.md) 进入.
