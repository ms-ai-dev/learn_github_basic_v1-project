# 回顾一下, 确认自己学到了什么

## 1. 目标

这是整门课的收尾, 不做新操作. 回头看一遍学过的东西, 确认自己现在能独立用 GitHub 干活了.

---

## 2. 检查清单

对着念一遍, 都能说出 "怎么做" 就说明学到手了:

- [ ] 知道这门课大致学了什么 (四块: 基本操作, 掌控访问权, 更顺手的工具, 认清仓库的归属).
- [ ] 会操作 GitHub: 建 repo, 改文件 commit, 开 branch, 用 PR 或 merge 合回 main.
- [ ] 会建 private repo, 分得清什么该 public 什么该 private.
- [ ] 会把一个人邀请成 collaborator.
- [ ] 知道怎么生成, 保存和撤销一个 access token.
- [ ] 会用 GitHub Desktop 在本地 clone, commit, push.
- [ ] 拿到一个仓库能说出它的 owner 是谁, 也知道去 organization 里找别人分享给你的仓库.

卡在哪条, 回去把对应那一节再翻一遍就好.
