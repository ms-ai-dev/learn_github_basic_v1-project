# 在网页端编辑 README 并提交到 main

## 1. 目标

在你上一节创建的 repo 上练习网页端编辑. 你要读懂如何浏览和编辑文件, 然后动手给 README.md 加上你的名字, 并用一次规范的 Commit 把改动保存到 main 分支. 完成后, 这次编辑会永久留在文件的修改历史里.

---

## 2. 要做的事情

1. 读本节 README, 理解如何在 GitHub 网页端浏览和编辑文件.
2. 打开你在上一节 (01 Create Repo) 创建的 repo.
3. 找到并点开 README.md, 点右上角铅笔图标进入编辑模式.
4. 在文件里加上一行你的名字 (比如 "Maintained by John Smith").
5. 点 "Commit changes...", 在 Commit message 里填 "Add my name to README", 确认选中 "Commit directly to the main branch", 再点绿色的 "Commit changes" 保存.
6. 回到文件详情页, 确认你的名字已经出现, 并在修改历史里看到这次编辑.

**小贴士:** 如果在手机上打字不方便, 可以让 AI 助手 (比如 Claude) 帮你生成内容放在 Artifact 里, 再复制粘贴进 GitHub 编辑器, 会省事很多.

**预计用时:** 15 分钟左右

---

## 3. 检查清单

- [ ] **读懂网页端浏览与编辑**: 你能说清如何打开文件, 如何进入编辑模式, 以及如何用 Commit Changes 保存.
- [ ] **完成动手练习**: README.md 里已经加上了一行你的名字.
- [ ] **用指定 Commit Message 保存成功**: 这次改动用 "Add my name to README" 作为 Commit Message 保存到 main, 并能在文件的修改历史里看到它.
