# Edit README on the Web and Commit to main

## 1. Goal

Practice web editing on the repo you created in the previous lesson. You will learn how to browse and edit files, then add your name to README.md and save the change to the main branch with one proper Commit. Once done, this edit stays permanently in the file's edit history.

---

## 2. What to Do

1. Read this lesson's README and understand how to browse and edit files on GitHub's web interface.
2. Open the repo you created in the previous lesson (01 Create Repo).
3. Find and click README.md, then click the pencil icon in the top-right corner to enter edit mode.
4. Add a line with your name to the file (such as "Maintained by John Smith").
5. Click "Commit changes...", enter "Add my name to README" in the Commit message, confirm that "Commit directly to the main branch" is selected, then click the green "Commit changes" to save.
6. Go back to the file detail view, confirm that your name now appears, and see this edit in the edit history.

**Tip:** If typing on a phone is inconvenient, you can have an AI assistant (such as Claude) generate the content for you in an Artifact, then copy and paste it into the GitHub editor to save a lot of hassle.

**Estimated time:** About 15 minutes

---

## 3. Checklist

- [ ] **Understand web browsing and editing**: You can explain how to open a file, how to enter edit mode, and how to save with Commit Changes.
- [ ] **Complete the hands-on exercise**: README.md now has a line with your name added.
- [ ] **Save successfully with the specified Commit Message**: This change is saved to main with "Add my name to README" as the Commit Message, and you can see it in the file's edit history.
