# Read the Series Index and Get a Map of the Course

## 1. Goal

This Task is reading only, nothing to build. Read through the map in this lesson's README: the parts this course breaks into, the problem each one solves, and why they run in this order. Then decide where you are starting. With that map in hand, every lesson you read afterwards has a place on the path.

---

## 2. What to Do

1. Read this lesson's README end to end, going over the nine group titles and the problem each one solves.
2. Open two or three of the mini tasks that interest you most and skim the opening of their READMEs to get a feel for the depth of this course.
3. Decide your starting point. If GitHub is completely new to you, start at 02 and read down by number; if you already know how to create a repo and edit files, you can jump straight to the part you need.

**Estimated time:** about 10 minutes

---

## 3. Checklist

- [ ] **Can name the parts**: You can say what the nine parts of this course are and roughly what problem each one solves.
- [ ] **Can name your starting point**: You can say which lesson you are starting with and why that one.
- [ ] **Can see the through-line**: You can say that this course starts in the browser and ends with a local desktop tool, which is why the early lessons all build on the same repo one after another, so you should avoid skipping around.
