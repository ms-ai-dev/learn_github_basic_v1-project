# 读一遍系列索引, 拿到整门课的地图

## 1. 目标

这个 Task 不动手, 只读. 通读本节 README 那张地图, 把这门课分成哪几块, 每块解决什么问题, 各块之间为什么是这个顺序过一遍, 然后决定自己从哪一篇开始往下走. 有了这张地图, 后面每读一篇你都知道自己站在整条路的哪个位置.

---

## 2. 要做的事情

1. 通读本节 README, 把九个分组的标题和它们各自解决的问题过一遍.
2. 点开其中两三篇你最感兴趣的 mini task, 扫一眼它们的 README 开头, 感受一下这门课的深浅.
3. 决定自己的起点. 完全没接触过 GitHub 就从 02 开始按编号读下去; 已经会建 repo 和改文件, 也可以直接跳到你需要的那一块.

**预计用时:** 10 分钟左右

---

## 3. 检查清单

- [ ] **说得出分块**: 你能说出这门课分成哪九块, 每块大致解决什么问题.
- [ ] **说得出起点**: 你能说出自己打算从哪一篇开始, 以及为什么是它.
- [ ] **认得这条主线**: 你能说出这门课是从纯网页操作起步, 一路走到本地桌面工具的, 所以前面几篇都在同一个 repo 上一篇接一篇地叠加, 尽量别跳着读.
