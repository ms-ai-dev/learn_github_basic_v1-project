# Move a Real Document to GitHub and Read Your Contribution Graph

## 1. Goal

Make the mindset shift from "using GitHub to turn in code homework" to "using GitHub for everything." You will learn to read a GitHub contribution graph, move a real non-code document into your own repo with your own hands, and be able to explain why this approach is worth more than any single technical skill in the age of AI.

---

## 2. What to Do

1. Read the whole lesson README, especially the GitHub plus AI and contribution graph sections, and do not skip the mentor's note.
2. Visit your own GitHub profile, find and explore your contribution graph, and click a green square to see what you committed that day.
3. Visit the public profile of an experienced developer or an active open source contributor, and compare the density and consistency of the two contribution graphs.
4. Think of a non-code document you wrote recently in Word or Google Docs, class notes, homework, any text will do.
5. Create a new file with a meaningful name in your own repo, and move the content of that document into it.
6. Write a meaningful commit message when you commit, not a lazy one like update or add file.

**Estimated time:** About 15 minutes

---
