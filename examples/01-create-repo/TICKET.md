# Create a Correctly Configured Public Repository

## 1. Goal

Create your first Repository by hand on the GitHub website. Through this task, you should truly understand the concept of a Repository, understand what each creation setting does, and end up with a Public Repo that you can keep using in the next several lessons.

---

## 2. What to Do

1. Read this lesson's README and understand what a Repository is, along with what each configuration item does (visibility, README, .gitignore, license).
2. Follow the steps in the README to get to the creation page and create a Repository. We recommend combining your name with the course topic to form the repository name (such as john-doe-learn-github-basic).
3. Configuration requirements: set Visibility to Public and check Add a README.
4. Click Create repository to finish, and land on the new Repo's home page.
5. Confirm in the file list that you can see README.md, and confirm that you can open your own Repo's home page.
6. Copy the Repo's URL, open it in your browser's incognito window, confirm that you can see it even without logging in, and notice the Public label at the top.

**Estimated time:** About 15 minutes

---

## 3. Checklist

- [ ] **Understand Repository**: After reading this lesson's README, you can explain in your own words what a Repository is and how it differs from an ordinary folder.
- [ ] **Created successfully**: You successfully created a Repository with Visibility set to Public.
- [ ] **README exists**: You can see the README.md file in the Repo's file list.
- [ ] **Home page accessible**: You can open your own Repo's home page and see the repository name in the top left and the README content in the center.
- [ ] **Verify Public visibility**: Open the Repo's URL in an incognito window and confirm that you can see all the content while not logged in, and see the Public label.
