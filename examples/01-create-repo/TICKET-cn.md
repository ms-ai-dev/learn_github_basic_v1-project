# 创建一个配置正确的 Private Repository

## 1. 目标

亲手在 GitHub 网页端创建你的第一个 Repository. 通过这个任务, 你要真正理解 Repository 这个概念, 读懂每一项创建配置的作用, 并得到一个可以在后续几节课里继续使用的 Private Repo.

---

## 2. 要做的事情

1. 阅读本节 README, 理解 Repository 是什么, 以及各个配置项 (visibility, README, .gitignore, license) 各自的作用.
2. 按 README 里的步骤进入创建页面, 创建一个 Repository. 名字随意, 建议用 your-name-first-repo 这种格式 (如 john-first-repo).
3. 配置要求: 把 Visibility 设为 Private, 并勾选 Add a README.
4. 点击 Create repository 完成创建, 跳转到新 Repo 主页.
5. 在文件列表里确认能看到 README.md, 并确认可以打开自己 Repo 的主页.

**预计用时:** 10 到 15 分钟

---

## 3. 检查清单

- [ ] **理解 Repository**: 读完本节 README, 能用自己的话说清 Repository 是什么, 以及它和普通文件夹的区别.
- [ ] **创建成功**: 成功创建了一个 Visibility 为 Private 的 Repository.
- [ ] **README 存在**: 在 Repo 的文件列表里能看到 README.md 文件.
- [ ] **主页可访问**: 能打开自己 Repo 的主页, 看到左上角的仓库名和中央的 README 内容.
