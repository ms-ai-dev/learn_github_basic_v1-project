# Learn GitHub Basics 总览

> 一句话: 这门课带你从零走完 GitHub 的基础工作流, 从纯网页操作起步, 落到本地的 GitHub Desktop. 想先了解全貌, 看 [README-ORIGINAL-cn.md](README-ORIGINAL-cn.md).

## 1. 这门课是什么

GitHub 是当今管理和协作文本的业内标准. 这门课手把手带一个完全没接触过 GitHub 的人上手它最核心的基础工作流, 全程不碰命令行, 学完就能把 GitHub 当作自己日常的主要工作区. 它也刻意不假设你是程序员: 开头就会讲清这个平台的底子是作品加社交, 任何想把自己做过的事留下记录, 摆出来给人看的人, 都用得上它.

这是一个 readup 类型的教学仓库: 整个 repo 就是一门课, 内容拆成 [examples/](examples/) 下一个个按编号排列的 Task. 你不用把它当成一本从头读到尾的大部头, 只要照下面 "怎么读" 的路子, 一篇篇顺着读下来, 边读边照每篇的 TICKET 做, 就能学会.

---

## 2. 怎么读

1. 进 [examples/](examples/), 从 01 开始按编号往下读. 第一篇是索引, 会给你整门课的地图, 告诉你它分成哪几块, 该按什么顺序走.
2. 每个 Task 目录里, 先读 README (这一篇教什么, 带你做什么), 再照它的 TICKET 把 "要做的事情" 逐项做完, 用 "检查清单" 自查是不是真的做到了.
3. 一篇读完再读下一篇, 直到读完最后一篇 (它会帮你梳理学到了什么, 并指出想更进一步可以往哪走).
4. 读到什么算成: 每个 Task 的 TICKET 检查清单都能逐项打勾, 且能不看教程自己把核心流程走一遍.

这门课的 Task 是一路长起来的: 中间那一大段都在你自己的同一个 repo 上操作, 一篇接一篇地叠加. 所以尽量按顺序读, 别跳着来.

---

## 3. 读完你能做到什么

读完这门课, GitHub 对你来说不再是一个陌生的程序员工具, 而是你日常协作和版本管理的默认主场: 你能独立建 repo, 改文件, 用 branch 和 Pull Request 干活, 拎得清什么该公开什么该私有, 把对的人请进来协作, 让程序凭 token 代表你操作, 能在自己电脑上用 GitHub Desktop 顺手地工作, 还能一眼看出一个仓库属于谁. 更重要的是, 你会有一个公开的, 带时间戳的地方来存放自己做过的东西, 而这份记录比任何自我介绍都有说服力.
