# Syllabus

## 01-readup

By the end you can run the full basic GitHub workflow on your own: create a repo, edit and commit in the browser, experiment safely on a branch and merge back into main with a Pull Request, tell public from private, invite collaborators, manage access tokens, work locally with GitHub Desktop, and tell who any repository belongs to. You also start by sorting out where Git and GitHub each came from and how they divide the work, see why that work plus social design is a door-opener even if you never write code, and build the habit of putting everything on GitHub. No command line anywhere.
