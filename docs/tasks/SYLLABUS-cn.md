# Syllabus

## 01-readup

学完你能独立走完 GitHub 的整套基础工作流: 建 repo, 在网页端编辑并 commit, 用 branch 安全实验再用 Pull Request merge 回 main, 分清 public 与 private, 邀请 collaborator, 管理 access token, 用 GitHub Desktop 在本地干活, 并认清每个仓库都挂在一个 owner 名下. 你还会先搞清 Git 与 GitHub 各自的来历与分工, 明白这套作品加社交的构造为什么对不写代码的人同样是敲门砖, 并养成把一切工作都放上 GitHub 的习惯. 全程不碰命令行.
