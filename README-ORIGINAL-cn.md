# learn_github_basic_v1-project

GitHub 是当今软件世界管理和协作文本的业内标准. 无论是代码, 文档还是任何以文字存在的信息, 它都能带上版本历史, 协作工具和永久的记录来管理. 这门课只教它最核心的网页端基础工作流, 让完全没接触过 GitHub 的人也能一步步上手, 全程只用浏览器, 不装任何软件, 不碰命令行.

学完你能独立在 GitHub 上创建并配置自己的 repository, 在浏览器里编辑文件并提交改动, 用 branch 开辟平行分支安全地实验, 再用 Pull Request 把成果合并回 main. 这是一条真实团队每天都在走的工作流, 掌握了它, 你就具备了参与现代协作项目的基本功. 课程定位是 basic 入门, 深度刚好覆盖 "能自己动手做完整一轮".

比操作更重要的是它想帮你建立的习惯: 把一切工作都放到 GitHub 上. 在 AI 时代, 一份日积月累, 可验证, 无法造假的记录, 比任何自我标榜都更有说服力, 而 GitHub 是唯一能让这种长期记录变得毫不费力的平台.
